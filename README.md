# DS-Mate plugins for Claude Code

The official Claude Code marketplace of [DS-Mate](https://www.ds-mate.com).

```
/plugin marketplace add DS-Mate/claude-code-plugins
/plugin install ds-mate@ds-mate
```

| Plugin | What it does |
| --- | --- |
| [ds-mate](plugins/ds-mate) | Read your DS-Mate dropshipping account from Claude Code: orders, stores, products, suppliers, eBay buyer messages, the dashboard summary and AliExpress product search. Read only. |
