# DS-Mate plugins for Claude Code

The official Claude Code marketplace of [DS-Mate](https://www.ds-mate.com).

```
/plugin marketplace add DS-Mate/claude-code-plugins
/plugin install ds-mate@ds-mate
```

| Plugin | What it does |
| --- | --- |
| [ds-mate](plugins/ds-mate) | Ask Claude Code about your DS-Mate dropshipping account: orders, stores, products, suppliers, unlinked variants, eBay buyer messages, the dashboard summary and AliExpress product search. You choose what Claude may do when you sign in; today it can only read. |
